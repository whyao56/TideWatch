# TideWatch · 观潮 —— 使用说明（Windows 免安装版）

这是一个**命令行工具**。双击 exe 只会看到一个黑窗口和一个按回车关闭的提示 ——
它需要你告诉它「分析哪份数据」。

---

## 三步开始

**1. 先自检**（强烈建议，10 秒）

按住 `Shift` 在文件夹空白处点右键 → 选「在此处打开 PowerShell 窗口」，然后：

```powershell
.\TideWatch.exe doctor
```

它会告诉你：版本号、程序在哪、配置文件在哪、规则库齐不齐、能不能真的出结论。
结论是 `ok` 或 `warn` 就说明能用。

**2. 拿自带样例跑一遍**

```powershell
.\TideWatch.exe scan data\sample\sample.jsonl --evidence
```

`--evidence` 会打印每一条可疑判定背后的原始证据（命中了哪条规则、贡献了多少分）。

**3. 换成你自己的数据**

```powershell
.\TideWatch.exe scan D:\我的数据\comments.jsonl --limit 30 --out 报告.md
```

报告是 Markdown，可以直接用 Typora / VS Code / Obsidian 打开。

---

## 数据格式

一行一个 JSON 对象（JSONL，UTF-8 编码）：

```json
{"item_id": "c1", "actor_id": "u1", "text": "评论内容", "created_at": 1788000000, "topic": "video-1001"}
```

只有 `text` 是必需的，其余缺失时对应信号会「不表态」而不是报错。
字段含义与更多可选字段见随包的 `README.md`。

## 常用命令

| 命令 | 作用 |
|---|---|
| `TideWatch.exe doctor` | 自检运行环境 |
| `TideWatch.exe scan 数据.jsonl` | 扫描数据，打印可疑目标 |
| `TideWatch.exe scan 数据.jsonl --evidence` | 连原始证据一起打印 |
| `TideWatch.exe scan 数据.jsonl --json` | 输出 JSON（方便接别的工具） |
| `TideWatch.exe scan 数据.jsonl --out 报告.md` | 写出 Markdown 报告 |
| `TideWatch.exe signals` | 列出全部 10 个信号及其原理 |
| `TideWatch.exe rules` | 查看规则库统计 |
| `TideWatch.exe --version` | 看版本号 |

加 `--help` 看任何子命令的完整参数。

## 怎么改规则 / 参数（不用写代码）

**改参数**：`configs\default.yaml`，或者命令行临时覆盖：

```powershell
.\TideWatch.exe scan 数据.jsonl --set scoring.levels.strong=45
```

**改话术库 / 正则 / 谐音表**：`rules\` 里的三个 YAML。
加几条自己在业务里见过的导流话术，保存即生效 —— 不用重新构建、不用装任何东西。

改动之后可以跑 `TideWatch.exe doctor`，它会打印**当前生效的配置指纹**
（指纹变了说明改动被读进去了）。

## 常见问题

**双击 exe 什么都没发生？**
它是命令行工具，请按上面的方式在终端里带参数运行。双击时会打印用法提示并停住，
不会一闪而过。

**Windows 提示「已保护你的电脑」/ SmartScreen 拦截？**
这是没有代码签名证书的免费开源程序的正常现象（签名证书一年几百美元，
本项目没有买）。点「更多信息」→「仍要运行」即可。
自行核对：`Get-FileHash .\TideWatch-<版本>-win64.zip -Algorithm SHA256`，
和下载页给的校验和比对。

**报错「找不到配置文件」？**
`configs\` 和 `rules\` 必须和 `TideWatch.exe` 在同一层。
如果你只把 exe 单独拷了出来，请把整个文件夹一起拷。

**程序目录改不动（装在 Program Files 里）？**
把压缩包解到桌面或 D 盘这类有写权限的目录再跑。
`doctor` 会提示你，并且会把默认规则复制一份到用户目录，
设环境变量 `TIDEWATCH_HOME` 指向它就能继续微调。

**想用自己的那一套规则，又不想动发行包？**

```powershell
$env:TIDEWATCH_HOME = "D:\我的规则"
.\TideWatch.exe doctor   # 确认「资源根」已经指过去
```

**结果看起来偏少 / 偏多？**
先看 `README.md` 的「已知限制」一节。这个引擎定位是
**把 10000 条评论缩到 200 条值得人看的**，不是自动封号 ——
结论只作为人工复核的线索。

## 合规边界

本工具**只做分析，不内置任何爬虫**。使用前请确认：

- 数据来源合法且已获授权；
- 不存储、不传播可识别到自然人的信息；
- 结论仅用于人工复核，**不得用于自动化处罚**。

详见 `README.md` 的「合规边界」。
